## Engineering Focus

- 운용조건에 따라 달라지는 성능 요구사항을 정의하고, 비교 가능한 시험 기준을 설계합니다.
- 단일 성능지표만으로 결론을 내리지 않고, 신뢰성, 자원효율, 안정성의 상충관계를 함께 분석합니다.
- 배열 가중치와 소자 배치 변화가 빔패턴에 미치는 영향을 시뮬레이션으로 분석하고, 목표 패턴과 보상 결과를 비교합니다.
- 실측 데이터와 시뮬레이션 결과를 바탕으로 원인을 구조화하고, 동일 조건에서 개선 효과를 검증합니다.

## Selected Projects

### C-V2X Adaptive CP Control

도심 LOS/NLOS 환경에서 수신 신뢰성과 자원효율을 함께 고려하는 DDQN 기반 적응형 CP 제어 프로젝트입니다.

- 운용 시나리오 및 성능지표 설정
- 고정 CP, 규칙 기반 CP, DDQN 방식 비교 검증
- PRR, 유효 RF 에너지 효율, CP 변동률 기반 결과 분석

[View Repository](https://github.com/ParkGeonJun02/cv2x-ddqn-adaptive-cp)

### Smart Antenna Beamforming Analysis

15소자 ULA 환경에서 Chebyshev 가중치 기반 빔패턴 형성, 빔 조향, 비등간격 배열의 Least Squares 가중치 보상을 분석한 MATLAB 프로젝트입니다.

- Chebyshev 가중치를 적용한 기준 빔패턴과 부엽 수준 확인
- -60°부터 +60°까지 10° 간격 빔 조향 비교
- 비등간격 배열에서 기준 패턴과 Least Squares 보상 결과 비교

[View Repository](https://github.com/ParkGeonJun02/smart-antenna-beamforming-analysis)

### Dense WLAN AP Quality Evaluation

실측 Wi-Fi 환경에서 RSSI, RTT, 채널 사용률을 활용해 AP 품질을 평가하고 추천하는 프로젝트입니다.

- MATLAB, iperf3 기반 통신 품질 데이터 수집
- 정상 및 혼잡 환경의 시험조건 설계
- 실제 전송률을 독립 검증지표로 활용한 평가 구조 검증

[View Repository](https://github.com/ParkGeonJun02/dense-wlan-ap-quality-evaluation)

### U-Net Riparian Zone Detection

고해상도 항공영상에서 수변구역을 탐지하고, 영역 분할과 경계 위치 정확도를 검증한 프로젝트입니다.

- Color and Texture 기반 Baseline 설계
- U-Net 결과의 오탐 및 경계 오류 분석
- Hybrid Pipeline 후처리와 정량 성능 비교

[View Repository](https://github.com/ParkGeonJun02/unet-han-river-riparian-zone-detection)
